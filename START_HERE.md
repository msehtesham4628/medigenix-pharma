## 🚀 QUICK START (5 Minutes)

### 1. Edit Configuration
```bash
Open: src/config.js
```

Update 3 fields:
- Line 10: `phone: '[Your Phone Number]'`
- Line 11: `email: '[Your Email Address]'`
- Line 12: `whatsapp: '[Your WhatsApp Number]'`
- Lines 71-72: Map coordinates (from Google Maps)

### 2. Save & Refresh
- Press Ctrl+S to save
- Browser auto-updates
- See your changes instantly!

### 3. Deploy
```bash
Option A: Vercel (recommended)
npm install -g vercel
vercel

Option B: Netlify
npm run build
# Drag dist/ folder to netlify.com

Option C: Your hosting
npm run build
# Upload dist/ folder via FTP
```

**That's it! You're live! 🎉**
